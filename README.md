I made my first 3D CAD file using Tinkercad, a beginner-friendly online design tool. I started by experimenting with basic shapes, learning how to move, resize, and combine them to form a simple 3D model. Once I finalized the design, I exported the file in .STL format and prepared it for printing using the 3D printer's slicing software. Since the printer was manual, I had to carefully set the bed level and filament feed myself before starting the print.
Watching my digital model gradually take shape layer by layer was a really satisfying experience and gave me my first hands-on insight into how digital design becomes a physical object.
